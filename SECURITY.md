# Security Policy

## Supported versions

This project is under active development and is preparing for store distribution.
Security fixes are applied on the default branch and included in GitHub Releases when maintainers cut a release.

Privacy practices for local data are described in [docs/PRIVACY.md](docs/PRIVACY.md).

## Reporting a vulnerability

Please **do not** open a public issue for vulnerabilities that could expose local user data (cars, fuelings, maintenance history, backups).

Preferred options:

1. GitHub **Private vulnerability reporting** (Security → Advisories → New draft advisory, or the repository Security tab “Report a vulnerability”), if enabled for this repository.
2. Otherwise contact the repository owner privately via their GitHub profile.

Maintainers: enable private reporting under **Settings → Code security → Private vulnerability reporting**.

Include:

- Description and impact
- Steps to reproduce or a proof of concept
- Affected platforms / versions if known

You should receive an acknowledgement when the maintainer is available. Please allow reasonable time before any public disclosure.
